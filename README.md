# 视频带货分析工作台

上传 Excel / CSV 后自动分析热销品类、新旧视频贡献、出单集中度、视频话术框架及录播二创画面建议，导出原生 Word 和 CSV。原页面布局、上传与字段对应流程保持不变。

## 识别与归因

1. 按公开视频作品 ID 复用已核验内容；缓存仅包含公开的主讲品、品类、字幕/画面证据，不含任何账号成交数据。
2. 对新出现且有成交的视频，后台尝试读取抖音详情页中与目标作品 ID 严格匹配的媒体资源。获取完整音轨转写，并采样开头、中段、后段画面读取字幕和商品形态。标题、标签、平台章节仅作线索。
3. 内容证据优先于标题。例如“牛仔裤”标签下实际讲灯芯绒工装裤，应归灯芯绒裤；牛仔工艺不能直接视为牛仔面料。搭配商品与主讲品区分。
4. 明确主讲品及品类后，按约定把视频 100% 的直接成交金额和订单归属主讲品。这是视频归因口径，不是平台商品订单明细。直接成交与引流成交分别统计。
5. 失效、需要登录、平台限制访问、无法取得实际内容或品类证据不足，保留待识别及原因；不会用标题猜测替代内容核验。零成交新视频不做付费分析，保留未核验状态。手动修正优先。
6. 话术部分区分已读取的原片内容证据与结构建议；示例开头不是原片逐字稿。画面建议用于筛选现有录播的全身、半身、下半身、近景、动态和搭配片段。

## 隐私与密钥

Excel/CSV 在浏览器解析，成交额、订单数、账号和整份文件不发到分析服务器。后台只接收公开视频链接/作品 ID 与标题；原音轨和采样帧会发送至 OpenAI API。媒体临时文件在提取后删除；服务不记录请求内容，任务结果在内存保留最多两小时，公开视频结果缓存有数量与有效期限制。浏览器刷新清空本地成交数据。无数据库。

`OPENAI_API_KEY` 仅放服务端环境变量。`.env.local` 与业务文件被 Git 和 Docker 排除；禁止把密钥放进 dist 或 GitHub。OpenAI 请求设置 store:false。自动分析需要有效 API 额度，密钥过期或额度不足时会明确提示并保留待识别。

## 本地验证

Node.js 22，ffmpeg/ffprobe（通过官方包管理器安装），无 npm 依赖。

```sh
npm test
node --env-file=.env.local server/index.mjs
```

打开 http://localhost:3000 。不配置密钥仍可体验演示、复用已核验公开视频结果；新视频会提示未配置。测试使用模拟模型，不消耗 API；真实媒体与模型访问必须部署后另行验证。

## GitHub + Render

原静态服务 `video-sales-studio` 继续发布 `dist`，公开地址不变。新增 Docker Web Service `video-sales-studio-api`，同一仓库 main 分支，使用根目录 Dockerfile（Node 22 与 Debian 官方 ffmpeg 包），Free 规格、健康检查 `/healthz`。环境配置见 render.yaml 和 .env.example，密钥在 Render Environment 中设置。前端公开配置 dist/config.mjs 只包含 API 地址。如果 Render 分配不同域名，需要同时修改该地址和 ALLOWED_ORIGINS。

后端每次最多 25 条、并发 2 条、每日默认最多 400 个新作品，队列与任务数量受限，重用同作品结果；限制或失败不会产生虚构分类。Free 服务可能冷启动，首次分析会有等待。服务重启会清空运行期缓存。

## 第三方库

SheetJS CE 0.20.3、docx 9.6.1 随站点本地托管。OpenAI 图像分析默认 gpt-5.6-terra，音轨转写默认 gpt-transcribe，可由服务端环境变量调整。模型服务、抖音访问限制或平台页面结构变化可能影响自动读取，已核验内容及本地成交汇总不受影响。
