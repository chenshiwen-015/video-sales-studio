# 出单观察室

浏览器本地解析 Excel 和 CSV 的视频带货分析工作台。支持字段对应、工作表选择、统计区间、新旧视频拆分、品类修正、参考视频、视频话术内容框架分析、录播素材二创画面类别与剪辑顺序建议，以及原生 Word 报告导出。

## 本地运行

在 `dist` 目录启动任意静态 HTTP 服务。无构建步骤和服务器数据存储，用户上传的文件仅驻留浏览器内存，不上传到服务器，也不持久保存。刷新或关闭页面会清空数据。Render 部署配置在仓库根目录 `render.yaml`。

## 校验

用 Node 运行 `tests/core.test.mjs`。额外传入原始报表绝对路径时，会核对报告中的总额、订单、品类和近期发布数据。真实报表不随网站源代码提交。

## 分析口径

优先使用表内品类，否则按标题关键词推断。规则涵盖服饰及部分常见消费品；不确定内容归入待识别，可逐条手动修正。话术框架依据品类及有成交且有标题的视频提取卖点出现次数，给出表达主线、分段内容和开头示例，用于筛选原录播话术。画面建议另行推荐全身、半身、下半身、细节近景、动态、搭配等素材及剪辑顺序。两部分并列保留，不代表已读取原片口播或画面，不调用大模型服务。

按文件名识别统计区间；否则按最新发布日期向前推定30天，并明确显示来源。统计区间仅用来拆分发布时间，不据此推导成交发生时间。金额与订单分别汇总，引流金额单列。缺失值不按零补齐；平均每单成交额只使用金额与订单均有效的记录。完全相同行可以忽略；重复视频ID而内容不同时保留并提示核对。

SheetJS CE 0.20.3 为从官方 CDN 固定版本复制的浏览器脚本；Word 使用 docx 9.6.1。第三方脚本随网站本地托管，分析过程无需向 CDN 请求脚本。

## GitHub + Render 部署

源码仓库：https://github.com/chenshiwen-015/video-sales-studio

在 Render 创建 **Static Site**，连接上述 GitHub 仓库，选择 `main` 分支：

- Build Command：`node tests/core.test.mjs`
- Publish Directory：`dist`
- Root Directory：留空
- 自动部署：每次提交到 `main` 后发布
- 环境变量：`NODE_VERSION=22`、`SKIP_INSTALL_DEPS=true`

也可以在 Render 创建 Blueprint，读取根目录 `render.yaml` 自动完成上述设置。

此项目无需数据库、后端服务或 API 密钥。上传的 Excel/CSV 在访问者浏览器中解析，不传到 Render 或 GitHub。真实业务表格、生成报告、测试截图和旧托管平台标识均不包含在部署源码内。
